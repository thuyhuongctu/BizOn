## Cần lưu ý
- **Không đưa dữ liệu cá nhân** (CCCD, ngày sinh, địa chỉ, SĐT) vào bất kỳ tệp nào ở đây — repo công khai.
- **Không đưa phương án/timeline nhãn hiệu** vào repo — giữ ở kênh riêng cho tới khi có số đơn.
- **Hash commit + ngày hoàn thành** do Hương tự chạy `git log` lấy, không dùng số công cụ AI báo.
- **Hai điểm Hương tự xác minh** (grep IB-CI = 0; duyệt phần lược hằng số đáp án) — xem §Tự-xác-minh trong hồ sơ chính.
- Đây là **tài liệu làm việc**, không phải tư vấn pháp lý; điểm pháp lý do luật sư SHTT xác nhận.
